### Requirements
- Python 3.8+
- `tqdm` (optional, for progress bars)
- JAX (optional, for GPU acceleration)

### Installation

```bash
# Clone the repository
git clone https://github.com/sparkainlp-x/quantum-error-correction-demo.git
cd quantum-error-correction-demo

# Install optional dependencies
pip install -r requirements.txt
```

### Run the Benchmark

```bash
# Production run (1 billion iterations, ~2-4 hours)
python oes32_v14_improved.py --iterations 1000000000 --erasure 0.20 -v

# Quick test (1 million iterations, ~2 minutes)
python oes32_v14_improved.py --iterations 1000000 --erasure 0.20

# Custom parameters
python oes32_v14_improved.py --iterations 100000000 --erasure 0.15 -v
```
